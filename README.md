# Kotlin

## À propos de ce répertoire
Ce répertoire regroupe des projets Kotlin réalisés pour découvrir ou approfondir l’écosystème Kotlin.

## Projets disponibles
- [ktor-koin-openapi](ktor-koin-openapi/readme.md) — API Kotlin basée sur Ktor, avec injection de dépendances via Koin, documentation OpenAPI, et build Gradle en Kotlin DSL.

- [spring-boot-swagger](spring-boot-swagger/readme.md) — API Kotlin basée sur springboot, documentation OpenAPI, et build Gradle en Kotlin DSL. Ce projet propose de pouvoir supporter plusieurs modes de stockage.
